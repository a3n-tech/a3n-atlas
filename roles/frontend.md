# Role: Frontend Developer

**Angle of attack:** UI matching the design, accessibility, performance on mobile.

**Pick up:** `role:frontend`, `ready-for-agent`

**Reach for first:**
- `/implement` per ticket with `/tdd`
- `brain/design/` + design tokens before any UI work
- `engineering-skills:senior-frontend`, `frontend-design`, `ui-ux-pro-max`
- `/design-review` and `/qa` on your preview URL
- `vercel:react-best-practices` patterns where they fit React Router

**Always:**
- Match the design exactly; deviations need a note in the PR
- 44px targets, real labels/buttons, 4.5:1 contrast, reduced motion
- Never invent copy — design text or a `[PLACEHOLDER]`

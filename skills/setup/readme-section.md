## Team harness

This repo runs the [a3n-tech harness](https://github.com/a3n-tech/harness): PAUL plans milestones and phases in `.paul/`,
the engineering skills build one ticket per branch, and hooks pass context between people and sessions.

- Rules and workflow: `CLAUDE.md` (between the `harness:team-rules` markers).
- Ticket, label and domain docs: `docs/agents/`.
- Per-person setup, brain editing in Obsidian, troubleshooting: [`docs/HARNESS-SETUP.md`](docs/HARNESS-SETUP.md).
- First time here: install the plugins Claude Code offers, then run `/harness:setup`.

## Atlas

This repo runs [Atlas](https://github.com/a3n-tech/atlas), the a3n-tech agentic team toolkit: PAUL plans milestones
and phases in `.paul/`, the engineering skills build one ticket per branch, hooks pass context between people and
sessions, and the central brain holds team context.

- Rules and workflow: `CLAUDE.md` (between the `harness:team-rules` markers).
- Ticket, label and domain docs: `docs/agents/`.
- Per-person setup, editing the brain, troubleshooting: [`docs/HARNESS-SETUP.md`](docs/HARNESS-SETUP.md).
- First time here: install Atlas (see that guide), then run `/a3ntech:setup`.

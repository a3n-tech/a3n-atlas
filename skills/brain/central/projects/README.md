# Projects

One folder per project repo. The folder name is exactly the GitHub repo name in the org
(`projects/<repo>/` for `<org>/<repo>`). The daily mirror reads that name to find the repo.

To add one, copy `project-template/` to `projects/<repo>/`, fill in its `index.md`, add a link in
[team hub](../index.md), and open a PR. Creating the folder needs a review because `index.md` is protected.

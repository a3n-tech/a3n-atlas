# Role: Full-stack Developer

**Angle of attack:** A ticket end to end: schema → API → UI → tests.

**Pick up:** `role:fullstack`, plus `role:frontend` / `role:backend` when unassigned

**Reach for first:**
- `/implement` per ticket with `/tdd`
- The frontend and backend sets
- `/qa` on the preview URL before review
- `/code-review`

**Always:**
- Follow both the frontend and backend rules
- Split a ticket that grows past one PR
